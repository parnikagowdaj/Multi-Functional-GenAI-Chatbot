# SmolLM2 Chatbot 🤖

A simple AI chatbot built using **Python, Hugging Face SmolLM2, and Streamlit**.

### Features

* AI-powered responses
* Simple Streamlit interface
* Runs locally

### Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

### Tech Stack

Python 
• Hugging Face 
• SmolLM2 
• Streamlit
